Add the Micronaut Vaadin dependency to your build, with its annotation processor:

dependency:io.micronaut.vaadin:micronaut-vaadin-core[]

dependency:io.micronaut.vaadin:micronaut-vaadin-processor[scope="annotationProcessor"]

The processor makes the classes Vaadin creates, such as views, into beans, and lets the application start Vaadin without scanning the classpath. See <<views, Views and Dependency Injection>>.

The integration is configured under the `vaadin` prefix. The property names match those of Vaadin's Spring Boot integration, so the Vaadin documentation applies unchanged:

[configuration]
----
vaadin:
  url-mapping: /ui/*
  exclude-urls:
    - /api/**
    - /health
----

Any other Vaadin initialization parameter can be set under the same prefix. For example, `vaadin.heartbeat-interval` sets `heartbeatInterval`.

The configuration is available as a bean:

snippet::io.micronaut.vaadin.docs.quickstart.VaadinConfigurationTest[tags="config", indent=0, title="Reading the Vaadin configuration"]

<1> Inject the `VaadinConfigurationProperties` bean.
<2> The URL mapping of the Vaadin servlet, `/*` by default.
