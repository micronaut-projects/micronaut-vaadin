Micronaut Vaadin

Integration between Micronaut and Vaadin Flow

Version: 1.0.0-SNAPSHOT

1 Introduction

This project integrates Vaadin Flow with Micronaut. Vaadin Flow lets you build web user interfaces in Java: views are server-side components, and Vaadin keeps the browser in sync.

The integration targets Vaadin 25 and Micronaut 5.3. It runs Vaadin on the default Netty server and on the servlet containers of Micronaut Servlet (Jetty, Tomcat and Undertow).

This project is under development. The configuration below is available; the Vaadin servlet, routing and scopes are not yet implemented.

2 Quick Start

Add the Micronaut Vaadin dependency to your build:

implementation("io.micronaut.vaadin:micronaut-vaadin-core")
<dependency>
    <groupId>io.micronaut.vaadin</groupId>
    <artifactId>micronaut-vaadin-core</artifactId>
</dependency>
[tool.pyronaut.dependencies]
runtime = [
    "io.micronaut.vaadin:micronaut-vaadin-core",
]

The integration is configured under the vaadin prefix. The property names match those of Vaadin’s Spring Boot integration, so the Vaadin documentation applies unchanged:

vaadin.url-mapping=/ui/*
vaadin.exclude-urls[0]=/api/**
vaadin.exclude-urls[1]=/health
vaadin:
  url-mapping: /ui/*
  exclude-urls:
    - /api/**
    - /health
[vaadin]
url-mapping = "/ui/*"
exclude-urls = ["/api/**", "/health"]
vaadin {
  urlMapping = "/ui/*"
  excludeUrls = ["/api/**", "/health"]
}
{
  vaadin {
    url-mapping = "/ui/*"
    exclude-urls = ["/api/**", "/health"]
  }
}
{
  "vaadin": {
    "url-mapping": "/ui/*",
    "exclude-urls": ["/api/**", "/health"]
  }
}

The configuration is available as a bean:

Reading the Vaadin configuration
@Inject
VaadinConfigurationProperties vaadin; // (1)

@Test
void readsTheVaadinConfiguration() {
    assertEquals("/ui/*", vaadin.getUrlMapping()); // (2)
    assertEquals(List.of("/api/**", "/health"), vaadin.getExcludeUrls());
}
Reading the Vaadin configuration
vaadin: Annotated[VaadinConfigurationProperties, Inject]  # (1)

@Test
def reads_the_vaadin_configuration(self) -> None:
    assert self.vaadin.getUrlMapping() == "/ui/*"  # (2)
    assert list(self.vaadin.getExcludeUrls()) == ["/api/**", "/health"]
Reading the Vaadin configuration
@Inject
lateinit var vaadin: VaadinConfigurationProperties // (1)

@Test
fun readsTheVaadinConfiguration() {
    assertEquals("/ui/*", vaadin.urlMapping) // (2)
    assertEquals(listOf("/api/**", "/health"), vaadin.excludeUrls)
}
Reading the Vaadin configuration
@Inject
VaadinConfigurationProperties vaadin // (1)

void "reads the Vaadin configuration"() {
    expect:
    vaadin.urlMapping == "/ui/*" // (2)
    vaadin.excludeUrls == ["/api/**", "/health"]
}
1 Inject the VaadinConfigurationProperties bean.
2 The URL mapping of the Vaadin servlet, /* by default.
