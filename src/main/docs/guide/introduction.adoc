This project integrates https://vaadin.com/flow[Vaadin Flow] with Micronaut. Vaadin Flow lets you build web user interfaces in Java: views are server-side components, and Vaadin keeps the browser in sync.

The integration targets Vaadin 25 and Micronaut 5.3. It runs Vaadin on the default Netty server and on the servlet containers of https://micronaut-projects.github.io/micronaut-servlet/latest/guide/[Micronaut Servlet] (Jetty, Tomcat and Undertow).

WARNING: This project is under development. Views, dependency injection, the Vaadin scopes, browserless testing, the Netty server, and the servlet containers of Micronaut Servlet are available, with development mode and push. File uploads are not yet available on Netty.
